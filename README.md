# Qabum Backend

Repositorio de soporte para datos cifrados y servicios auxiliares de Qabum.

## Novolov Localizador

`novolov/localizador/data.enc.json` contiene únicamente un snapshot cifrado de los campos operativos autorizados del localizador. No contiene costos, proveedores, documentos de compra ni credenciales en texto plano.
